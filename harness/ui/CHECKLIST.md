# Cierre visual

- [ ] BEFORE y target inspeccionados, misma ruta/estado/viewport/tema/datos comparables.
- [ ] Marca actual preservada; excepciones de marca explícitas y acotadas.
- [ ] Referencia externa evaluada como adaptación, sin copiar su identidad.
- [ ] Patch reutiliza componentes, tokens y convenciones; no oculta contenido funcional.
- [ ] Target desktop cumplido y mobile objetivo validado, si existe.
- [ ] Sin target mobile: responsive anterior preservado en el viewport declarado.
- [ ] Sin overflow o wrapping accidental; fuentes y assets reales cargados.
- [ ] Controles afectados funcionan; foco, teclado y etiquetas accesibles preservados.
- [ ] Checks pertinentes ejecutados; errores nuevos de consola revisados.
- [ ] Si se tocó algo compartido, consumidores representativos comprobados.
- [ ] AFTER de la última edición inspeccionado y guardado; sin ediciones posteriores.
- [ ] Pasadas, diff, pendientes y resultado registrados en la misma tarea.

Marcar cada punto PASS / FAIL / NO VERIFICADO / NO APLICA con motivo y evidencia.
Un criterio necesario NO VERIFICADO impide DONE. Build verde no prueba parecido visual;
una captura correcta no prueba funcionalidad. No sumar revisores por costumbre.
