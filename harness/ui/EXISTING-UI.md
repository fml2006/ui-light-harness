# Mapa mínimo del proyecto

Completar una vez durante onboarding; el agente reutiliza y corrige solo datos verificados.
No es un inventario completo. Los campos vacíos no autorizan inventar comandos.

- Raíz app / framework / gestor de paquetes:
- Comando existente de arranque / directorio / URL local:
- Comprobación de que está lista:
- Navegador o herramienta de capturas disponible:
- Cómo fijar viewport, DPR y guardar capturas:
- Datos locales o fixture / acceso a pantalla (sin contraseñas aquí):
- Tema / locale / fuentes y assets locales:
- Ubicación de rutas, componentes, CSS y tokens:
- Fuentes de marca existentes (logo / fuentes / paleta / tokens; detalle en BRAND-SOURCES.md):
- Componentes compartidos que conviene conocer:
- Comandos locales existentes: typecheck / lint dirigido / build / tests pertinentes:
- Interacciones mínimas de referencia:
- Viewport mobile existente de comprobación, si no hay target mobile:
- Responsable / fecha de última verificación:

Usar primero scripts del proyecto y herramientas ya disponibles. No instalar browser,
MCP ni dependencias automáticamente para una tarea cosmética. La captura debe provenir
del render de la app: nunca sustituirla por una imagen generada. No conectarse a datos
productivos ni ejecutar acciones reales de compra/envío para probar una interacción.
